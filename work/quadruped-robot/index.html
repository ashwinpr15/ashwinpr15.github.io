Other project · Engineering capstone

Quadruped robot for vision-based navigation and IoT monitoring

My BE capstone: a 12-servo, four-legged robot with camera-based navigation and IoT sensor monitoring, documented in a 35-page report.

Where
SDM Institute of Technology
When
2021
Hardware
Raspberry Pi, 12 servos, PCA9685
Software
Python, OpenCV, ThingSpeak

What's in the repository

  • PCA9685 servo control, leg calibration, a standing pose and a forward gait.
  • Camera navigation: filtering, Canny edges and region scanning to choose a direction.
  • DHT11 temperature and humidity readings published to ThingSpeak.
  • The full 35-page report: hardware, gait design, navigation and streaming.

Limitations

The checked-in code is part of the system in the report: backward and turning gaits are missing, and navigation prints decisions rather than driving the legs.
